# Frontend Rules

Frontend is built using:

- React
- Tailwind CSS
- React Router DOM
- fetch
- Framer Motion

---

## Frontend Goals

- Fully responsive
- Dynamic content from backend
- Modern portfolio UI
- Smooth animations
- Optimized performance

---

## Folder Structure

src/
├── components/
├── pages/
├── layouts/
├── services/
├── context/
├── hooks/
├── utils/

---

## Rules

- Use functional components
- Use reusable cards/components
- Keep UI professional
- Use loading spinners
- Add toast notifications
- Use environment variables
- replace a fetch with axios
